# 实现决策

- 保持 Python 3.10、FastAPI、SQLite、HTTPX、pytest 的技术方向。API 只负责接收与查询；不在 API 中调用供应商或启动 BackgroundTasks。
- 使用标准库 sqlite3，每次操作独立连接，显式关闭连接。同步路由由 FastAPI 在线程池执行，避免数据库等待阻塞异步事件循环。
- 创建任务的事务退出并成功提交后才返回 202；数据库错误返回不包含内部细节的 503，启动初始化失败则启动失败。
- 使用本机 SQLite 文件、WAL、FULL 同步、有限锁等待；时间统一为整数 Unix 秒。schema 包含 Worker 所需 Lease 字段与索引，使用同一张任务表。
- body 必填但允许 null，接受标准 JSON 值，拒绝非有限浮点数；序列化一次存入数据库，供后续 Worker 原样发送。
- 目标只接受 ASCII HTTPS URL、默认/显式 443 端口，域名大小写不敏感且精确匹配 allowlist。拒绝 IP literal、URL 用户信息、fragment 和空端口；国际化域名可使用 punycode。默认空 allowlist 拒绝所有目标。
- Header 名称按大小写不敏感规则校验，拒绝重复、服务保留头、逐跳头及控制字符。允许供应商凭据但不向状态接口暴露。验证错误不回显输入，避免敏感数据泄露。
- API 测试使用临时磁盘数据库及 TestClient，覆盖独立连接可见性、提交失败回滚、应用重建持久化、JSON 各值类型、输入校验与脱敏。

域名 allowlist 不能解决全部 SSRF 风险，数据库中的凭据也未加密；这些限制不应被描述为生产级安全保证。

## 阶段 2 实现决策

- 单 Worker 串行处理，使用 asyncio 驱动 AsyncClient；SQLite 操作放入线程，以保持事件循环可用。没有增加并发任务池、续租或独立清理进程。
- BEGIN IMMEDIATE 短事务中先清理耗尽的过期 Lease，再选择并条件更新一个可执行任务。领取时间在取得写锁后计算，避免锁等待使租约时间陈旧。结果写回同样在取得写锁后读取时间，严格检查 token、状态和租约有效期。
- 配置 10 秒 HTTPX 阶段超时，同时 asyncio.wait_for 限制总投递时间；60 秒 Lease 提供余量。HTTP 流式读取到状态码即关闭响应，不消耗响应正文。禁用重定向与环境代理。
- 原样发送已保存的 UTF-8 JSON，稳定添加 Idempotency-Key。默认补充 application/json；显式空 Cookie 阻止共享 Client 的 Cookie jar 在后续任务或重试中隐式增加凭据，调用方明确提供的 Cookie 仍保持原值。
- 退避在 0.8–1.2 Jitter 后四舍五入至整数秒，与时间存储精度一致；最终延迟不超过 300 秒。不解析 Retry-After。
- 固定错误摘要避免异常字符串、URL 查询参数和响应正文泄密。Worker 入口关闭 HTTPX/httpcore 的 INFO 日志，自己的日志仅含任务 ID、次数、结果和写回是否生效。
- 数据库写回异常与供应商错误分离，保留 PROCESSING 等待 Lease 恢复；不把本地持久化失败误判为供应商未收到。程序错误不统一吞掉，进程退出后仍可通过 Lease 恢复。
- 发送前重新校验当前域名 allowlist，已移除的目标进入 FAILED。运维需为 API 和 Worker 设置同一 allowlist。
- 自动化测试加入独立连接同时领取、旧 token 与过期结果拒绝、连续五次崩溃不发第六次、发送成功后写回失败再恢复、重试字节和 Headers 稳定、总超时取消及流式响应关闭。

## 阶段 3 审查修复

- JSON 序列化改为 ASCII 转义形式，避免解码后的孤立 Unicode 代理字符导致 SQLite UTF-8 编码失败；正常 Unicode 的业务值保持一致，Worker 仍发送已保存的字节。
- 校验错误位置只保留固定顶层字段，不回显额外字段名或嵌套键名。错误类型保留，便于调用方判断校验问题。
- Header 值首尾空格直接返回 422，避免接受后被 HTTP 协议实现拒绝；不通过隐式 strip 修改调用方凭据。
- 三类缺陷先补测试并确认共 8 个用例失败，再实施小范围修复。另增加真实进程直接退出恢复、转义 JSON 投递和日志脱敏测试，完整测试共 90 项通过。详见 review.md。

## 最终验收后修复

- HTTPX InvalidURL 不属于 RequestError，原先的分类未覆盖超长 URL。输入端直接使用已依赖的 HTTPX URL 解析器验证，避免复制其私有长度常量；Worker 同时兜底处理历史无效数据，标为 FAILED 并继续后续任务。
- 先确认两项新增回归测试失败，再修复并完整运行测试：92 项通过，1 条第三方弃用警告。
